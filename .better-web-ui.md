## Design Context

### Users

Blessings Global Outreach serves supporters, volunteers, donors, event attendees, prayer partners, and administrators. Public visitors need to understand the ministry, see real outreach work, find events, volunteer, pray, and give with confidence. Administrators need clear, dependable tools for managing the same work.

### Brand Personality

Faith-centered, compassionate, and credible. The experience should feel welcoming and human while remaining polished enough to earn trust from partners and donors. Language should be warm, direct, and free of invented claims.

### Aesthetic Direction

Use the real Blessings Movement identity and outreach photography. Preserve the modern cool-neutral palette, strong contrast, Sora display typography, Manrope body typography, restrained violet accents, gently rounded surfaces, and purposeful motion. Support both light and dark themes. Avoid muddy brown surfaces, browser-default blue controls, excessive empty space, decorative clutter, stock imagery, and motion that competes with the message.

### Implementation Defaults

Preserve the detected stack: Next.js 14 App Router, React 18, TypeScript, Tailwind CSS 3, custom global design tokens, Framer Motion, Lucide icons, and Radix Select for headless select controls. The project uses custom form state and validation rather than a shared form library. No table framework or virtualization layer is currently established. Reuse existing components and tokens before adding dependencies.

### Design Principles

- Let real ministry stories and photography carry the emotion; do not manufacture proof or impact claims.
- Establish hierarchy through readable type, contrast, and tight grouping before adding decoration.
- Keep related content close and remove empty space that interrupts the page narrative.
- Use familiar, accessible controls with branded focus and motion; never rely on browser-default styling.
- Keep one clear primary action per section and make it easy to find on every screen size.
